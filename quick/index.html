Projects

PHAROS Context and memory infrastructure for coding agents

What if code search had to prove which version of the code every answer came from?

Built a code-intelligence service: Tree-sitter indexing of symbols, imports and calls; dense, sparse and keyword retrieval fused by rank; every cited source checked against its commit; served to agents over REST and native MCP.

Held-out nDCG@10 rose 0.394 → 0.697 and 0.463 → 0.726 on 101 questions ◐ Reported. Repository memory v1 failed its primary gate at 55% audited precision, and stays beside the win.

Technical detail

Auto mode prefers dense retrieval, uses hybrid with hints and falls back to keyword with a warning. Explicitly requested modes that are unavailable fail. Source context is checked against the indexed Git blob SHA, which proves integrity, not correctness. Sparse (SPLADE) retrieval is implemented in its earlier search module; the audited auto mode does not route to the sparse retriever.

Valerie / CognitiveOS A native assistant with a deterministic action boundary

What if an assistant could propose anything, but only fixed rules could decide what runs?

Built a native SwiftUI app for macOS and iOS where a model proposes one typed move and deterministic code validates it against issued state before anything runs. The same boundary runs this site’s guide.

LongMemEval retrieval R@5 0.908 over 500 questions ◐ Reported: retrieval only, not answer accuracy.

R&Bot Can a small model learn the shape of a song, not just its words?

A 33M-parameter transformer trained from scratch over four epochs on about 50M tokens, with section tokens for verse, chorus and bridge ◆ Owner confirmed.

BABEL What does a novel look like when it is staged as a scene?

How I work

  1. Reframe the problem. Start from a better question than the one on the ticket.
  2. Decide what would prove it. Write the bar down before building, so the result can’t move it.
  3. Make it something you can touch. Build the smallest version a person can actually try.
  4. Measure, and keep what fails. Report the result against the bar, and publish the misses beside the wins.
