Recorded runs

  1. A question reaches verified sourceOne question, asked the way an assistant asks it: a real MCP call, a real dense search, and five files fetched from GitHub and checked against their Git blobs.
  2. Hints turn auto into hybridThe same question with two guessed identifiers. Auto becomes hybrid, and the function that actually does the check moves from fifth to first.
  3. What the blob check does with a mismatchThe same pointer through the same call, three times. Only the expected SHA changes.
  4. A missing embedder: degrade with a warning, or refuseNo embedder at all. Auto degrades and says so. Asking for a mode that cannot run is refused.
  5. Who calls this, and what does it call?An assistant asks where one function lives and what touches it. A real MCP call finds the definition, then reads the resolved call graph around it.
