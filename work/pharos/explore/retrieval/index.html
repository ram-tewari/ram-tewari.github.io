Retriever

Keyword, dense, hybrid and graph modes, with the mode used always reported.

▣ Recorded run

PHAROS at 975a38dMIT license

How it works

Auto is dense when dense can run, and hybrid when the caller passes hints. If embeddings are unavailable it falls back to keyword and says so. An explicit mode that cannot run is refused.

Hybrid is reciprocal rank fusion of keyword and dense, with a boost for an exact symbol name. Tests, docs and examples are down-ranked unless the question asks for them.

Recorded runs through it

  1. Hints turn auto into hybridThe same question with two guessed identifiers. Auto becomes hybrid, and the function that actually does the check moves from fifth to first.
  2. A missing embedder: degrade with a warning, or refuseNo embedder at all. Auto degrades and says so. Asking for a mode that cannot run is refused.

Limits

  • Repository scope is a filter the caller chooses. A call that names no repository searches every repository in the index.
  • The retrieval metrics are read from project documentation. They were not reproduced for this site.

Claims this supports

  • PHAROS supports keyword, dense, hybrid and graph retrieval; auto prefers dense, hybrid with hints, keyword fallback with warnings.
