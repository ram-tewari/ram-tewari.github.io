PHAROS, CognitiveOS / ValerieTwo control boundariesPHAROS compares source with the Git blob recorded at indexing. A mismatch withholds the code, but with no recorded blob the code is returned marked unverified. Valerie checks typed moves against issued state before native engines run them. Both checks are deterministic code, not a model’s judgement.
PHAROS, CognitiveOS / ValerieTwo kinds of memoryPHAROS keeps repository evidence and conventions. Valerie keeps sourced temporal facts and a ledger.
BABEL, CognitiveOS / ValerieTyped outputBABEL validates chapters against a typed schema on its batch path, but its single-chapter path accepts looser blocks, so validation is inconsistent. Valerie validates typed moves against issued state before native engines run them.
